TELNET (Terminal Network) provides a bidirectional, text-oriented communication facility over network connections[cite: 1].

> [!definition] TELNET
> **TELNET** is an application layer client-server protocol operating over TCP port 23 that grants a user terminal access to execute programs and manage resources on a remote host machine[cite: 1].

* **Transport Mechanism**: Utilizes a reliable, byte-oriented TCP connection[cite: 1].
* **Port Assignment**: TCP Well-Known Port **23**[cite: 1].
* **Operational Characteristics**: Provides remote terminal emulation; transmits all keystrokes, commands, and authentication credentials in plain text without native cryptographic protection[cite: 1].
