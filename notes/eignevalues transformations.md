Let $A$ be a matrix with eigenvalues $\lambda_1, \lambda_2, \lambda_3, \dots$.

## Transformations of $A$

| Matrix | Eigenvalues |
| :--- | :--- |
| $A$ | $\lambda_1, \lambda_2, \lambda_3, \dots$ |
| $A^{-1}$ | $\lambda_1^{-1}, \lambda_2^{-1}, \lambda_3^{-1}, \dots$ |
| $A^n$ | $\lambda_1^n, \lambda_2^n, \lambda_3^n, \dots$ |
| $kA$ | $k\lambda_1, k\lambda_2, k\lambda_3, \dots$ |
| $A + kI$ | $\lambda_1 + k, \lambda_2 + k, \lambda_3 + k, \dots$ |
| $A^T$ | $\lambda_1, \lambda_2, \lambda_3, \dots$ (Same as $A$) |
| $\text{Adj}(A)$ | $\frac{\det(A)}{\lambda_1}, \frac{\det(A)}{\lambda_2}, \frac{\det(A)}{\lambda_3}, \dots$ |

# Examples:

Given eigenvalues of $2 \times 2$ matrix $X$ are $\lambda_1 = -2$ and $\lambda_2 = -3$. Find the eigenvalues of $(X + I)^{-1}(X + 5I)$.

1. **For $\lambda_1 = -2$:** $$ \frac{-2 + 5}{-2 + 1} = \frac{3}{-1} = -3 $$
2. **For $\lambda_2 = -3$:** $$ \frac{-3 + 5}{-3 + 1} = \frac{2}{-2} = -1 $$
