The fastest way to solve cyclic sum ratios like this is to find the total sum first.

**Step 1: Find $a + b + c$**

Add all three terms together:

$$(a + b) + (b + c) + (c + a) = 5 + 7 + 6$$

$$2(a + b + c) = 18 \implies a + b + c = 9$$

**Step 2: Find individual values of $a$, $b$, and $c$**

Subtract each given pair from the total sum ($9$):

- $c = (a + b + c) - (a + b) = 9 - 5 = 4$
    
- $a = (a + b + c) - (b + c) = 9 - 7 = 2$
    
- $b = (a + b + c) - (c + a) = 9 - 6 = 3$
    

So, $a = 2$, $b = 3$, and $c = 4$.

**Step 3: Evaluate the required ratio**

- **Numerator:** $a - b + c = 2 - 3 + 4 = 3$
    
- **Denominator:** $a + b - c = 2 + 3 - 4 = 1$
    

$$\frac{a - b + c}{a + b - c} = \frac{3}{1}$$

The correct option is **(c) 3 : 1**.
