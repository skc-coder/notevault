# Trapezium & Isosceles Trapezium

## 1. Core Definition & Median
A quadrilateral with at least one pair of parallel sides ($AB \parallel CD$).
- **Median Line**: Line joining midpoints of non-parallel sides is parallel to the base and equals half the sum of parallel sides:
  $$\text{Median} = EF = \frac{a + b}{2}$$

## 2. Diagonal Proportionality & Sub-Triangles
- Diagonals intersect each other proportionally:
  $$\frac{AO}{OC} = \frac{BO}{OD} = \frac{AB}{CD} = \frac{a}{b}$$
- **Area Ratio of Similar Triangles**:
  $$\frac{\text{Area}(\Delta AOB)}{\text{Area}(\Delta COD)} = \frac{AB^2}{CD^2} = \frac{a^2}{b^2}$$
- **Non-Parallel Sub-Triangles**:
  $$\text{Area}(\Delta AOC) = \text{Area}(\Delta BOD) = \sqrt{\text{Area}(\Delta AOB) \times \text{Area}(\Delta COD)} = a b$$

## 3. Length of Diagonals (Euler-Trapezium Identity)
In any trapezium $ABCD$ with $AB \parallel CD$:
$$AC^2 + BD^2 = AD^2 + BC^2 + 2(AB \cdot CD)$$

## 4. Isosceles Trapezium
A trapezium where non-parallel sides are equal ($AD = BC$).
- Diagonals are equal ($AC = BD$).
- Base angles are equal ($\angle A = \angle B$ and $\angle C = \angle D$).
- **Cyclic Property**: Every isosceles trapezium is cyclic (can be inscribed in a circle).

## 5. Formulas
- **Area**: $\frac{1}{2} (a + b) \cdot h = \text{Median} \times h$
- **Perimeter**: $a + b + c + d$
