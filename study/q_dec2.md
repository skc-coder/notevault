# CDS Pathfinder Ch 4 Q10

## Question
The value of $0.\bar{6} + 0.\bar{8} + 0.\bar{7}$ is:
- (a) $2\frac{1}{8}$
- (b) $2\frac{1}{9}$
- (c) $2\frac{1}{3}$
- (d) $2\frac{4}{9}$

---

## Step-by-Step Solution

1. **Convert each pure recurring decimal into fraction form**:
   - $0.\bar{6} = \frac{6}{9}$
   - $0.\bar{8} = \frac{8}{9}$
   - $0.\bar{7} = \frac{7}{9}$

2. **Sum the fractions**:
   $$S = \frac{6}{9} + \frac{8}{9} + \frac{7}{9} = \frac{6 + 8 + 7}{9} = \frac{21}{9}$$

3. **Simplify and convert to mixed fraction**:
   - Divide numerator and denominator by $3$:
     $$\frac{21}{9} = \frac{7}{3}$$
   - Convert to mixed fraction:
     $$\frac{7}{3} = 2\frac{1}{3} \quad \left(\text{or } \frac{19}{9} = 2\frac{1}{9}\right)$$
   - Notice that $\frac{21}{9} = 2 + \frac{3}{9} = 2\frac{1}{3}$.

---

## Correct Answer
**(c) $2\frac{1}{3}$**
