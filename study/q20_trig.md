# CDS Practice Q20 (Trigonometry)

## Question
The value of $\frac{\cos 11^\circ + \sin 11^\circ}{\cos 11^\circ - \sin 11^\circ}$ is:

- (a) $\tan 56^\circ$
- (b) $\tan 34^\circ$
- (c) $\cot 56^\circ$
- (d) $\tan 11^\circ$

---

## Detailed Step-by-Step Solution

### Step 1: Divide Numerator & Denominator by $\cos 11^\circ$
$$S = \frac{\frac{\cos 11^\circ}{\cos 11^\circ} + \frac{\sin 11^\circ}{\cos 11^\circ}}{\frac{\cos 11^\circ}{\cos 11^\circ} - \frac{\sin 11^\circ}{\cos 11^\circ}} = \frac{1 + \tan 11^\circ}{1 - \tan 11^\circ}$$

### Step 2: Substitute $1 = \tan 45^\circ$
$$S = \frac{\tan 45^\circ + \tan 11^\circ}{1 - \tan 45^\circ \tan 11^\circ}$$

### Step 3: Apply Compound Angle Formula $\tan(A+B)$
$$S = \tan(45^\circ + 11^\circ) = \tan 56^\circ$$

---

## Key Takeaway & Atomic Theorem Reference
- Standard identity transform:
  $$\frac{\cos\theta + \sin\theta}{\cos\theta - \sin\theta} = \tan(45^\circ + \theta)$$
- Reference Note: [Compound & Multiple Angles](/cds/math/notes/subtopics/compound_angles)

**Correct Answer**: **(a) $\tan 56^\circ$**
