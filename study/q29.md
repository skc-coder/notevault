# CDS Practice Q29

## Question
If $7\cos^2\theta + 3\sin^2\theta = 4$ and $0 < \theta < \frac{\pi}{2}$, then what is the value of $\tan\theta$?

- (a) $\sqrt{7}$
- (b) $\frac{\sqrt{7}}{3}$
- (c) $\sqrt{3}$
- (d) $\frac{1}{\sqrt{3}}$

---

## Detailed Step-by-Step Solution

### Step 1: Split Terms into $\sin^2\theta + \cos^2\theta$
Write $7\cos^2\theta$ as $4\cos^2\theta + 3\cos^2\theta$:
$$4\cos^2\theta + 3\cos^2\theta + 3\sin^2\theta = 4$$
$$4\cos^2\theta + 3(\cos^2\theta + \sin^2\theta) = 4$$

### Step 2: Use Identity $\cos^2\theta + \sin^2\theta = 1$
$$4\cos^2\theta + 3(1) = 4 \implies 4\cos^2\theta = 1 \implies \cos^2\theta = \frac{1}{4}$$
Since $0 < \theta < \pi/2$, $\cos\theta > 0$:
$$\cos\theta = \frac{1}{2} \implies \theta = 60^\circ$$

### Step 3: Compute $\tan\theta$
$$\tan\theta = \tan 60^\circ = \sqrt{3}$$

---

## Key Takeaway & Atomic Theorem Reference
- Linear combination identity elimination: $a\cos^2\theta + b\sin^2\theta = c$.
- Reference Note: [Fundamental Identities & Ratios](/cds/math/notes/subtopics/trig_identities)

**Correct Answer**: **(c) $\sqrt{3}$**
