## 🗂️ 3.1 Introduction to Graphs

### Storing Graphs

Need to store **both** the set of nodes $V$ and set of edges $E$.

---

### Adjacency Matrix

$$A(i,j) = 1 \iff (i,j) \in E$$

- Size: $V \times V$ matrix
- Symmetric for **undirected** graphs

```
Undirected Example:        Directed Example:
   a b c d                    a b c d
a [0 1 0 1]              a  [0 0 0 1]
b [1 0 1 1]              b  [1 0 1 0]
c [0 1 0 1]              c  [0 0 0 0]
d [1 1 1 0]              d  [0 1 1 0]
```

---

### Adjacency List

Each vertex stores a **list of its neighbors**.

```
Undirected:              Directed:
a → [b] → [d]           a → [d]
b → [a] → [d] → [c]     b → [a] → [c]
c → [d] → [b]           c → (empty)
d → [a] → [b] → [c]     d → [c] → [b]
```

> [!tip] Key Observation
> 
> - **Undirected graph:** Number of external nodes in adjacency list = **2E** _(Each list represents the degree of that node)_
> - **Directed graph:** External nodes = **E** = sum of out-degrees of all vertices

---

### ⚖️ Adjacency List vs Adjacency Matrix Comparison

|Operation|Adjacency List|Adjacency Matrix|
|---|---|---|
|**Space**|$\Theta(V + E)$|$\Theta(V^2)$|
|**Test if** $u \to v \in E$|$\Theta(1 + \deg(u))$|$\Theta(1)$|
|**List v's neighbors**|$\Theta(1 + \deg(v))$|$\Theta(V)$|
|**List all edges**|$\Theta(V + E)$|$\Theta(V^2)$|
|**Insert edge uv**|$\Theta(1)$|$\Theta(1)$|
|**Delete edge uv**|$\Theta(1 + \deg(u) + \deg(v))$|$\Theta(1)$|

---

### 📊 Algorithm Runtime & Graph Density

Graph algorithm runtimes depend on $|V|$ and $|E|$.


|Graph Type|Relation|

|**Sparse graph**|$\|E\| \approx \|V\|$|

## 🔍 Graph Traversal & Search

> Graph traversal is different from tree traversal:
> 
> - Trees: ordered, obvious start, obvious end
> - Graphs: **any order**, **any start**, end is **not obvious**

**Commonly used search methods:**

- Breadth-First Search (BFS)
- Depth-First Search (DFS)

---

## 🔎 3.2 Searching Algorithm

### Whatever-First Search (General Framework)

```
Whatever-first-search(G, s):
    put s in the bag
    while bag is not empty (no marked left):
        Extract v from bag
        if v is unmarked:
            mark v
            for each edge (v, w):
                put w into the bag
```

> [!note] Bag Implementation
> 
> - **Stack** → Depth-First Search (DFS)
> - **Queue** → Breadth-First Search (BFS)

> [!warning] Simply deleting nodes instead of marking them is not effective because the node may be added again due to its neighbors and if being in bag means to visit then we have a loop!
---

## 🌲 3.2.1 Depth-First Search (DFS)

> **Thumb rule:** If there are no new nodes during traversal to visit → **backtrack**

### DFS Tree Example

```
DFS(a):
    a
    ↓
    b
   / \
  c   d
      |
      e → f
```

_(This forms the Depth-First Tree / DFT)_

### Discovery & Finish Times

| Term                       | Definition                                               |
| -------------------------- | -------------------------------------------------------- |
| **Start / Discovery time** | Time at which a vertex is visited **for the first time** |
| **Finish time**            | Time at which a vertex is visited **last time**          |

---
### Implementation of DFS

```python
DFS_Visit(u):
    d[u] = time++          # record discovery time
    visited[u] = true
    for each v adjacent to u:
        if not visited[v]:
            DFS_Visit(v)
    f[u] = time++          # record finish time (assign time to node)
```

```python
DFS(G):
    for each vertex u in vertices:
        visited[u] = false    
    time = 0
    for each u in vertices:
        if visited[u] == false:
            DFS_Visit(u)
```

**Time complexity:**
Focus on what is being done. The DFS algo visits each node and does the simple tasks of marking them, and updating time.
So, TC = "nodes" in the representation.

| Method           | Time to explore all nodes                       | Node             |
| ---------------- | ----------------------------------------------- | ---------------- |
| Adjacency List   | $1 + \deg(v_i)$ per vertex → Total: $O(V + 2E)$ | Linked nodes     |
| Adjacency Matrix | $V$ per vertex → Total: $O(V^2)$                | The matrix cells |

### 📐 DFS Parentheses Theorem

> **Lecture 22a**

In any DFS of a **directed or undirected** graph $G = (V, E)$, for any two vertices $u$ and $v$, **exactly one** of the following three conditions holds:

1. **Disjoint intervals:**
    
    - $[u.d,\ u.f]$ and $[v.d,\ v.f]$ are entirely disjoint
    - Neither $u$ nor $v$ is a descendant of the other in the DFS forest
2. **u inside v:**
    
    - $[u.d,\ u.f] \subset [v.d,\ v.f]$
    - $u$ is a **descendant of** $v$ in a DFS tree
3. **v inside u:**
    
    - $[v.d,\ v.f] \subset [u.d,\ u.f]$
    - $v$ is a **descendant of** $u$ in a DFS tree

### 🏷️ DFS Edge Classification

> **Lecture 22b**
> https://medium.com/@vikramsetty169/edge-types-in-graph-traversal-1c3545c61234

We first find DFS tree, which is directed.
The edges define kids and papa set for each vertex.

Now using this set and the edges of the original graph, we categorize the the (latter) edges as:

| Edge Type        | Definition                                         |
| ---------------- | -------------------------------------------------- |
| **Tree edge**    | Edge in the DFS forest                             |
| **Forward edge** | Not a tree edge; goes from **papa → kid**          |
| **Back edge**    | Not a tree edge; goes from **kid → papa**          |
| **Cross edge**   | Not a tree edge; neither papa nor kid relationship |

#### Example:
![[../../attachments/Pasted image 20260313085126.webp]]

```
Tree edges:    (a,b), (a,c), (b,d), (d,e), (e,f)
Forward edges: (a,d), (a,f), (d,f)
Back edge:     (e,a)
Cross edges:   (g,h), (c,d), (c,e), (h,d)
```

#### Edge Types in DFS — Summary Table

| Graph Type     | Possible Edge Types        |
| -------------- | -------------------------- |
| **Directed**   | Tree, Cross, Back, Forward |
| **Undirected** | Tree, Back                 |

> [!note] Why no Cross/Forward edges in Undirected DFS? In undirected graphs, direction of edges is not defined — so cross edges would become subtree edges, and similarly there are **no forward edges**.

> [!important] Key Theorem **A graph has a cycle if and only if there is a back edge**
> 
> Equivalently: **No back edge ↔ Acyclic graph**
> 
> This holds for both directed and undirected graphs.
