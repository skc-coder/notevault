# CDS Practice Q33: Simultaneous Dual Quadratic HCF Parameters

## Question Text

Find the values of $a$ and $b$ so that the polynomials:
$$P(x) = (x^2 + 2x + a)(x^2 + 3x + 2)$$
$$Q(x) = (x^2 + 7x + 12)(x^2 + 7x + b)$$
have $(x + 1)(x + 3)$ as their HCF.

**Options:**
- (a) $a = -3, b = 6$
- (b) $a = 3, b = -6$
- (c) $a = 6, b = -3$
- (d) None of these

---

## Detailed Mathematical Solution

### Step 1: Analyze Factor Structure of Given Parts
- $P(x) = (x^2 + 2x + a)(x + 1)(x + 2)$
- $Q(x) = (x + 3)(x + 4)(x^2 + 7x + b)$

### Step 2: Compare Factors with Specified HCF
The required HCF is $(x + 1)(x + 3)$.
- For $P(x)$: The factor $(x + 1)$ is already present in $(x^2 + 3x + 2)$. Therefore, $(x + 3)$ must be a factor of the remaining quadratic $(x^2 + 2x + a)$.
- For $Q(x)$: The factor $(x + 3)$ is already present in $(x^2 + 7x + 12)$. Therefore, $(x + 1)$ must be a factor of the remaining quadratic $(x^2 + 7x + b)$.

### Step 3: Solve for $a$ using Root Substitution $x = -3$ in $P(x)$
$$(-3)^2 + 2(-3) + a = 0 \implies 9 - 6 + a = 0 \implies 3 + a = 0 \implies a = -3$$

### Step 4: Solve for $b$ using Root Substitution $x = -1$ in $Q(x)$
$$(-1)^2 + 7(-1) + b = 0 \implies 1 - 7 + b = 0 \implies -6 + b = 0 \implies b = 6$$

Thus, $a = -3$ and $b = 6$.

**Correct Answer**: **(a) $a = -3, b = 6$**

---

## Key Takeaway & Exam Strategy
When HCF of factored polynomials is given, match existing linear factors first! The missing linear factor must belong to the quadratic containing the unknown parameter.
