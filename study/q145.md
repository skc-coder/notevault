# CDS Practice Q145

## Question
A triangle $\Delta ABC$ is inscribed in a circle of radius $R$. If the sum of squares of its sides is equal to twice the square of its diameter, then $\sin^2 A + \sin^2 B + \sin^2 C$ is equal to:

- (a) $2$
- (b) $3$
- (c) $4$
- (d) None of these

---

## Detailed Step-by-Step Solution

### Step 1: Use Sine Rule for Side Lengths
By the Sine Rule:
$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$$
$$a = 2R \sin A, \quad b = 2R \sin B, \quad c = 2R \sin C$$

### Step 2: Translate Given Condition
Given:
$$a^2 + b^2 + c^2 = 2 \times (\text{Diameter})^2 = 2 \times (2R)^2 = 8R^2$$

### Step 3: Substitute Expressions for $a, b, c$
$$(2R \sin A)^2 + (2R \sin B)^2 + (2R \sin C)^2 = 8R^2$$
$$4R^2 \sin^2 A + 4R^2 \sin^2 B + 4R^2 \sin^2 C = 8R^2$$
$$4R^2 (\sin^2 A + \sin^2 B + \sin^2 C) = 8R^2$$

### Step 4: Solve for $\sin^2 A + \sin^2 B + \sin^2 C$
$$\sin^2 A + \sin^2 B + \sin^2 C = \frac{8R^2}{4R^2} = 2$$

---

## Key Takeaway & Atomic Theorem Reference
- Extended Sine Rule: $a = 2R \sin A$.
- Reference Note: [Extrema & Triangle Properties](/cds/math/notes/subtopics/trig_extrema)

**Correct Answer**: **(a) $2$**
