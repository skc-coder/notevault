# CDS Practice Q138

## Question
What are the maximum and minimum values of $f(\theta) = 3\sin\theta + 4\cos\theta$?

- (a) $5$ and $-5$
- (b) $7$ and $-7$
- (c) $1$ and $-1$
- (d) $25$ and $-25$

---

## Detailed Step-by-Step Solution

### Step 1: Identify Formula Parameters
For $f(\theta) = a\sin\theta + b\cos\theta$, here $a = 3$ and $b = 4$.

### Step 2: Compute Radius $R = \sqrt{a^2 + b^2}$
$$R = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$$

### Step 3: Write Extrema Bounds
$$-\sqrt{a^2 + b^2} \le a\sin\theta + b\cos\theta \le \sqrt{a^2 + b^2}$$
$$-5 \le 3\sin\theta + 4\cos\theta \le 5$$

Maximum Value $= 5$, Minimum Value $= -5$.

---

## Key Takeaway & Atomic Theorem Reference
- Linear combination amplitude:
  $$f(\theta) = R \sin(\theta + \phi) \implies \text{Extrema} = \pm \sqrt{a^2 + b^2}$$

**Correct Answer**: **(a) $5$ and $-5$**
