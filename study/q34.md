# Question 34: De-Morgan & Difference Laws Simplification

## Question
What is $\{[(A \cup B)' \cap (A - B)] - (A - B)\}$ equal to?
- (a) $\emptyset$
- (b) $A$
- (c) $B$
- (d) $B'$

---

## Detailed Solution

### Method 1: Using Set Difference Identity $X - X = \emptyset$
Let $X = (A - B)$.
The given expression has the structure:
$$\{ [\text{Some Set}] \cap X \} - X$$

Let $Y = (A \cup B)' \cap (A - B)$.
Notice that $Y \subseteq (A - B)$.
Then we are computing $Y - (A - B)$.
Since $Y \subseteq (A - B)$, removing all elements of $(A - B)$ from $Y$ leaves no elements at all!

Therefore:
$$\{[(A \cup B)' \cap (A - B)] - (A - B)\} = \emptyset$$

### Method 2: Algebraic Derivation Step-by-Step
1. Recall set difference law: $P - Q = P \cap Q'$.
2. Let $E = [(A \cup B)' \cap (A \cap B')] \cap (A \cap B')'$.
3. By De-Morgan's law:
   $$(A \cup B)' = A' \cap B'$$
4. So inner term:
   $$(A' \cap B') \cap (A \cap B') = (A' \cap A) \cap (B' \cap B') = \emptyset \cap B' = \emptyset$$
5. Thus the entire left term evaluates to $\emptyset$.
6. $\emptyset - (A - B) = \emptyset$.

---

## Key Takeaway & Pattern
- Any set expression of the form $S - S$ or $Y - X$ where $Y \subseteq X$ simplifies instantly to the empty set $\emptyset$.
- $(A \cup B)'$ and $(A - B)$ are disjoint because $(A \cup B)'$ contains elements outside both $A$ and $B$, whereas $(A - B)$ contains elements inside $A$. Their intersection is $\emptyset$.
