# CDS Percentage Q147

## Question
When $40\%$ of a number is added to $42$, the result is the number itself. What is the number?
- (a) $70$
- (b) $90$
- (c) $82$
- (d) $72$

---

## Detailed Solution

### Step 1: Define the unknown number algebraically
Let the required number be $N$.

### Step 2: Set up the percentage equation
We are given:
$$\frac{40}{100} N + 42 = N$$

Simplify the fraction $\frac{40}{100} = \frac{2}{5}$:
$$\frac{2}{5} N + 42 = N$$

### Step 3: Solve for $N$
Subtract $\frac{2}{5} N$ from both sides:
$$42 = N - \frac{2}{5} N$$
$$42 = \frac{3}{5} N$$

Multiply both sides by $\frac{5}{3}$:
$$N = 42 \times \frac{5}{3} = 14 \times 5 = 70$$

---

## Correct Answer
**(a) 70**
