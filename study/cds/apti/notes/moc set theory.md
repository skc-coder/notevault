# Function Types

- **Into (not onto)** → not every codomain element is hit
- **Onto (Surjective)** → every codomain element is hit

(into, onto) -> codomain

- **Injective (One-to-one)** → no two inputs share the same output
- **Bijective** = Injective (one-one) + Surjective (onto) = one to one correspondence
- k to one: every element in codomain has k preimages.
