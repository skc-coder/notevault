# Equated Simple Interest & Capital Partitioning Theorem

When a total sum $P$ is divided into multiple parts $P_1, P_2, P_3, \dots, P_n$ lent at rates $R_1, R_2, \dots, R_n$ for times $T_1, T_2, \dots, T_n$:

## Case A: Equal Simple Interest Earned

If interest earned from each part is equal:
$$P_1 R_1 T_1 = P_2 R_2 T_2 = \dots = P_n R_n T_n = k$$

The principal allocation ratio is inversely proportional to rate-time product:
$$P_1 : P_2 : P_3 = \frac{1}{R_1 T_1} : \frac{1}{R_2 T_2} : \frac{1}{R_3 T_3}$$

## Case B: Equal Maturity Amounts Received

If final amount received from each part is equal:
$$P_1 \left(1 + \frac{R_1 T_1}{100}\right) = P_2 \left(1 + \frac{R_2 T_2}{100}\right) = \dots = P_n \left(1 + \frac{R_n T_n}{100}\right)$$

The principal allocation ratio is:
$$P_1 : P_2 : P_3 = \frac{1}{100 + R_1 T_1} : \frac{1}{100 + R_2 T_2} : \frac{1}{100 + R_3 T_3}$$
