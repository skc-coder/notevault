# Cylinder, Cone & Frustum of Cone

## 1. Right Circular Cylinder

A cylinder generated by rotating a rectangle around one of its sides as axis.

### Solid Cylinder (Radius $r$, Height $h$)
- **Volume ($V$)**:
  $$V = \pi r^2 h = \text{Base Area} \times \text{Height}$$
- **Curved Surface Area ($\text{CSA}$)**:
  $$\text{CSA} = 2\pi rh$$
- **Total Surface Area ($\text{TSA}$)**:
  $$\text{TSA} = \text{CSA} + 2 \times \text{Base Area} = 2\pi rh + 2\pi r^2 = 2\pi r(r + h)$$

### Hollow Cylinder (Outer Radius $R$, Inner Radius $r$, Height $h$)
- **Volume of Material**:
  $$V = \pi (R^2 - r^2) h$$
- **Total Surface Area**:
  $$\text{TSA} = 2\pi Rh + 2\pi rh + 2\pi (R^2 - r^2) = 2\pi (R + r)(h + R - r)$$

## 2. Right Circular Cone

A solid generated by revolving a right-angled triangle about one of its perpendicular sides.

### Formulas (Base Radius $r$, Vertical Height $h$, Slant Height $l$)
- **Slant Height ($l$)**:
  $$l = \sqrt{r^2 + h^2}$$
- **Volume ($V$)**:
  $$V = \frac{1}{3} \pi r^2 h = \frac{1}{3} \times \text{Cylinder Volume}$$
- **Curved Surface Area ($\text{CSA}$)**:
  $$\text{CSA} = \pi r l = \pi r \sqrt{r^2 + h^2}$$
- **Total Surface Area ($\text{TSA}$)**:
  $$\text{TSA} = \text{CSA} + \text{Base Area} = \pi r l + \pi r^2 = \pi r (r + l)$$

---

## 3. Frustum of a Right Circular Cone

When a cone is cut by a plane parallel to its base, the bottom portion remaining between the cutting plane and the base is a **Frustum**.

### Formulas (Top Radius $r$, Base Radius $R$, Height $h$, Slant Height $L$)
- **Slant Height ($L$)**:
  $$L = \sqrt{h^2 + (R - r)^2}$$
- **Volume ($V$)**:
  $$V = \frac{1}{3}\pi h (R^2 + r^2 + R r)$$
- **Curved Surface Area ($\text{CSA}$)**:
  $$\text{CSA} = \pi (R + r) L$$
- **Total Surface Area ($\text{TSA}$)**:
  $$\text{TSA} = \text{CSA} + \pi R^2 + \pi r^2 = \pi \left[ (R + r)L + R^2 + r^2 \right]$$

### Cone Similarity Ratios
If a cone of height $H$ and base radius $R$ is sliced parallel to the base at height $h$ from top:
$$\frac{r}{R} = \frac{h}{H}$$
$$\frac{V_{\text{top}}}{V_{\text{total}}} = \left(\frac{h}{H}\right)^3, \quad \frac{\text{CSA}_{\text{top}}}{\text{CSA}_{\text{total}}} = \left(\frac{h}{H}\right)^2$$

---

## 4. Key Formulas Comparison

| Solid | Volume ($V$) | CSA / LSA | TSA |
| :--- | :--- | :--- | :--- |
| **Cylinder** | $\pi r^2 h$ | $2\pi rh$ | $2\pi r(r+h)$ |
| **Cone** | $\frac{1}{3}\pi r^2 h$ | $\pi r l$ | $\pi r (r+l)$ |
| **Frustum** | $\frac{1}{3}\pi h(R^2+r^2+Rr)$ | $\pi (R+r)L$ | $\pi(R+r)L + \pi R^2 + \pi r^2$ |
