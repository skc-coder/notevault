# CDS Practice Question 57

## Question
In a $200\text{ m}$ race, $A$ can beat $B$ by $50\text{ m}$ and $B$ can beat $C$ by $8\text{ m}$. In the same race, $A$ can beat $C$ by what distance?
- (a) $60\text{ m}$
- (b) $72\text{ m}$
- (c) $56\text{ m}$
- (d) $66\text{ m}$

---

## Detailed Solution & Proof

### Step 1: Ratio of Speeds
- Race distance $L = 200\text{ m}$.
- When $A$ runs $200\text{ m}$, $B$ runs $200 - 50 = 150\text{ m}$:
  $$\frac{S_A}{S_B} = \frac{200}{150}$$

- When $B$ runs $200\text{ m}$, $C$ runs $200 - 8 = 192\text{ m}$:
  $$\frac{S_B}{S_C} = \frac{200}{192}$$

### Step 2: Calculate $\frac{S_A}{S_C}$
$$\frac{S_A}{S_C} = \frac{S_A}{S_B} \times \frac{S_B}{S_C} = \frac{200}{150} \times \frac{200}{192} = \frac{4}{3} \times \frac{25}{24} = \frac{100}{72} = \frac{200}{144}$$

### Step 3: Distance $C$ covers when $A$ finishes $200\text{ m}$
When $A$ runs $200\text{ m}$, $C$ runs $144\text{ m}$.

### Step 4: Calculate Deficit
Distance by which $A$ beats $C$:
$$\text{Deficit} = 200 - 144 = 56\text{ m}$$

*(Alternatively using Variation 32 formula $z = x + y - \frac{xy}{L}$)*:
$$z = 50 + 8 - \frac{50 \times 8}{200} = 58 - 2 = 56\text{ m}$$

**Correct Option**: **(c) $56\text{ m}$**
