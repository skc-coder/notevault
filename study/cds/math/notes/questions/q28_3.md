# CDS Practice Question 28.3

## Question
Find the median deposit balance from the continuous frequency distribution given below:

| Class Interval (`₹`) | Frequency ($f$) |
| :--- | :--- |
| 0 – 100 | 26 |
| 100 – 200 | 68 |
| 200 – 300 | 145 |
| 300 – 400 | 242 |
| 400 – 500 | 188 |
| 500 – 600 | 65 |
| 600 – 700 | 16 |

- (a) 356.0
- (b) 300.0
- (c) 356.2
- (d) 360.5

---

## Detailed Solution & Derivation

### 1. Cumulative Frequency Table

| Class Interval | Frequency ($f$) | Cumulative Frequency ($cf$) |
| :--- | :--- | :--- |
| 0 – 100 | 26 | 26 |
| 100 – 200 | 68 | 94 |
| 200 – 300 | 145 | 239 |
| **300 – 400** | **242** | **481** |
| 400 – 500 | 188 | 669 |
| 500 – 600 | 65 | 734 |
| 600 – 700 | 16 | 750 |

### 2. Identifying Median Class
- Total frequency $N = 750$.
- Half value:
  $$\frac{N}{2} = \frac{750}{2} = 375$$
- The cumulative frequency just greater than 375 is **481**.
- Therefore, the **Median Class** is **300 – 400**.

### 3. Applying Continuous Median Formula
- Lower limit $l = 300$
- Frequency of median class $f = 242$
- Cumulative frequency of preceding class $c = 239$
- Class width $h = 100$

$$M_e = l + \left( \frac{\frac{N}{2} - c}{f} \right) \cdot h$$
$$M_e = 300 + \left( \frac{375 - 239}{242} \right) \times 100$$
$$M_e = 300 + \left( \frac{136}{242} \right) \times 100$$
$$M_e = 300 + \frac{13600}{242} = 300 + 56.1983 \approx 356.2$$

---

## Final Answer
- **Correct Option**: **(c) 356.2**
