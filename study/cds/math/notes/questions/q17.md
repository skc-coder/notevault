# CDS Practice Question 17

## Question Statement
If $6\text{ men}$ and $8\text{ boys}$ can do a piece of work in $10\text{ days}$, while $26\text{ men}$ and $48\text{ boys}$ can do the same work in $2\text{ days}$, what is the time taken by $15\text{ men}$ and $20\text{ boys}$ to do the same work?

- (a) $4\text{ days}$
- (b) $5\text{ days}$
- (c) $6\text{ days}$
- (d) $7\text{ days}$

---

## Detailed Step-by-Step Solution

1. **Formulate Total Work Equations**:
   Let 1 man's 1-day work be $m$ and 1 boy's 1-day work be $b$.
   Total Work $W$:
   $$W = 10(6m + 8b) = 60m + 80b$$
   Also, from the second condition:
   $$W = 2(26m + 48b) = 52m + 96b$$

2. **Equate and Solve for Efficiency Ratio**:
   $$60m + 80b = 52m + 96b$$
   $$8m = 16b \implies m = 2b$$

3. **Calculate Total Work Units in terms of Boy Efficiency ($b$)**:
   Substitute $m = 2b$ into total work equation:
   $$W = 60(2b) + 80b = 120b + 80b = 200b$$

4. **Determine 1-Day Work Rate of Target Group ($15\text{ men} + 20\text{ boys}$)**:
   $$E_{\text{target}} = 15m + 20b = 15(2b) + 20b = 30b + 20b = 50b$$

5. **Calculate Required Days**:
   $$D = \frac{W}{E_{\text{target}}} = \frac{200b}{50b} = 4\text{ days}$$

- **Correct Option**: **(a) 4 days**
