# NDA 2016 I Q48

## Question

If $x = \frac{\sqrt{a+2b} + \sqrt{a-2b}}{\sqrt{a+2b} - \sqrt{a-2b}}$, then the value of $bx^2 - ax + b$ (given that $b \ne 0$) is equal to:

- (a) $0$
- (b) $1$
- (c) $ab$
- (d) $2ab$

**Answer**: **(a) 0**

---

## Method 1: The Ranker's Substitution Shortcut

Pick convenient numerical values for $a$ and $b$ to make the terms inside the square roots perfect squares.

- Let $a + 2b = 9$ and $a - 2b = 1$.
- Adding the two equations:
  $$2a = 10 \implies a = 5$$
- Subtracting the two equations:
  $$4b = 8 \implies b = 2$$

Now, substitute these into the given expression for $x$:

$$x = \frac{\sqrt{9} + \sqrt{1}}{\sqrt{9} - \sqrt{1}} = \frac{3 + 1}{3 - 1} = \frac{4}{2} = 2$$

Finally, evaluate the target expression $bx^2 - ax + b$:

$$2(2)^2 - 5(2) + 2 = 8 - 10 + 2 = 0$$

Hence, the answer is **(a) 0**.

---

## Method 2: Rigorous Algebraic Proof

Using **Componendo and Dividendo** $\left(\text{if } \frac{p}{q} = \frac{c}{d} \implies \frac{p+q}{p-q} = \frac{c+d}{c-d}\right)$ on $\frac{x}{1}$:

- Step 1: Apply Componendo & Dividendo to $x$:
  $$\frac{x+1}{x-1} = \frac{2\sqrt{a+2b}}{2\sqrt{a-2b}} = \frac{\sqrt{a+2b}}{\sqrt{a-2b}}$$

- Step 2: Square both sides:
  $$\frac{(x+1)^2}{(x-1)^2} = \frac{a+2b}{a-2b} \implies \frac{x^2 + 2x + 1}{x^2 - 2x + 1} = \frac{a+2b}{a-2b}$$

- Step 3: Apply Componendo & Dividendo a second time:
  $$\frac{(x^2 + 2x + 1) + (x^2 - 2x + 1)}{(x^2 + 2x + 1) - (x^2 - 2x + 1)} = \frac{(a+2b) + (a-2b)}{(a+2b) - (a-2b)}$$

  $$\frac{2(x^2+1)}{4x} = \frac{2a}{4b} \implies \frac{x^2+1}{2x} = \frac{a}{2b}$$

- Step 4: Cross-multiply and simplify:
  $$b(x^2 + 1) = ax$$
  $$bx^2 + b = ax \implies bx^2 - ax + b = 0$$

---

## Key Takeaways

1. **Componendo & Dividendo Double-Pass**: When an expression contains $\frac{\sqrt{A}+\sqrt{B}}{\sqrt{A}-\sqrt{B}}$, applying C&D once isolates the ratio of square roots $\frac{\sqrt{A}}{\sqrt{B}}$. Squaring and applying C&D a second time isolates the linear ratio $\frac{A}{B}$.
2. **Value Substitution Strategy**: Assigning perfect square values to $A$ and $B$ allows instant verification without manual algebraic manipulations.
