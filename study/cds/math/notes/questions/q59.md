# Question 59: Empty Set Identity with Universal Set

## Question
If $A$ is a non-empty subset of a set $E$, then what is $E \setminus (A \cup (A \cap (A - \emptyset) - \emptyset))$ equal to?
- (a) $A$
- (b) Complement of $A$
- (c) $\emptyset$
- (d) $E$

---

## Detailed Solution

### Step 1: Simplify Inner Operations with Empty Set
1. $A - \emptyset = A$ (Subtracting empty set leaves set unchanged).
2. $A \cap (A - \emptyset) = A \cap A = A$.
3. $(A \cap A) - \emptyset = A - \emptyset = A$.

### Step 2: Evaluate Outer Expression
1. $A \cup A = A$.
2. The entire expression inside brackets reduces to $A$.
3. Finally, evaluate $E - A = E \setminus A$.

By definition, $E - A$ (where $E$ acts as the universal set) is the **Complement of $A$** (denoted $A'$).

Hence, option **(b) Complement of A** is correct.

---

## Key Takeaway & Pattern
- $\emptyset$ acts as the identity element for set union and set difference: $A \cup \emptyset = A$ and $A - \emptyset = A$.
- Universal set difference $E - A$ is precisely $A^c$ or $A'$.
