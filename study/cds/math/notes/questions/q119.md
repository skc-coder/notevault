# Question 119: Minimum Value of Reciprocal Sum via AM-GM Inequality

For any positive real number $x > 0$, what is the minimum value of $x + \frac{9}{x}$?

(a) 3  
(b) 6  
(c) 9  
(d) 10  

> [!faq]- View Solution
> **AM-GM Inequality Concept:**  
> For any positive real numbers $a$ and $b$:
> $$\frac{a + b}{2} \ge \sqrt{a b} \implies a + b \ge 2 \sqrt{ab}$$
> Equality holds if and only if $a = b$.
> 
> **Step-by-Step Derivation:**  
> Set $a = x$ and $b = \frac{9}{x}$:
> $$x + \frac{9}{x} \ge 2 \sqrt{x \cdot \frac{9}{x}}$$
> $$x + \frac{9}{x} \ge 2 \sqrt{9} = 2 \times 3 = 6$$
> 
> Equality occurs when $x = \frac{9}{x} \implies x^2 = 9 \implies x = 3$.
> Thus, the minimum value is 6.
> 
> **Correct Answer:** **(b) 6**
