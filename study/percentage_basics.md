# Percentage Basics & Fractional Conversion

## Theory & Conceptual Proofs

### 1. The Per-Cent Operator
A percentage represents a ratio out of a base of $100$:
$$x\% = \frac{x}{100}$$

### 2. Standard Fraction to Percentage Equivalence Table
For rapid exam calculation, memorize these core unit fraction conversions:

$$\frac{1}{2} = 50\%$$
$$\frac{1}{3} = 33.33\% = 33\frac{1}{3}\%$$
$$\frac{1}{4} = 25\%$$
$$\frac{1}{5} = 20\%$$
$$\frac{1}{6} = 16.66\% = 16\frac{2}{3}\%$$
$$\frac{1}{7} = 14.28\% = 14\frac{2}{7}\%$$
$$\frac{1}{8} = 12.5\% = 12\frac{1}{2}\%$$
$$\frac{1}{9} = 11.11\% = 11\frac{1}{9}\%$$
$$\frac{1}{10} = 10\%$$
