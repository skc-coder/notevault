# CDS Pathfinder Ch 4 Q8

## Question
When $0.232323\dots$ is converted into a fraction, then the result is:
- (a) $\frac{1}{5}$
- (b) $\frac{2}{9}$
- (c) $\frac{23}{99}$
- (d) $\frac{23}{100}$

---

## Step-by-Step Solution

1. **Identify the decimal structure**:
   - The decimal $0.232323\dots = 0.\overline{23}$ is a **pure recurring decimal**.
   - The repeating period consists of $n = 2$ digits, which are $23$.

2. **Apply Theorem 1 (Pure Recurring Decimal Conversion)**:
   - For a pure recurring decimal with $n$ repeating digits:
     $$0.\overline{a_1 a_2} = \frac{a_1 a_2}{10^2 - 1} = \frac{a_1 a_2}{99}$$
   - Here, $a_1 a_2 = 23$:
     $$0.\overline{23} = \frac{23}{99}$$

3. **Verification via Direct Algebra**:
   - Let $x = 0.232323\dots$
   - Multiply both sides by $100$:
     $$100x = 23.232323\dots$$
   - Subtract original equation ($100x - x$):
     $$99x = 23$$
     $$x = \frac{23}{99}$$

---

## Correct Answer
**(c) $\frac{23}{99}$**
