# Dishonest Dealer and False Weights

## Theory & Mathematical Formulation

A dishonest trader claims to sell goods at cost price ($\text{SP} = \text{CP}$ per true unit measure), but cheats by delivering a smaller false weight or measure ($W_{\text{false}} < W_{\text{true}}$).

### 1. Fundamental Profit Invariant

- The profit arises because the dealer charges money for $W_{\text{true}}$ but only incurs cost for $W_{\text{false}}$.
- **Gain Percentage Formula**:
  $$\text{Gain } \% = \left( \frac{W_{\text{true}} - W_{\text{false}}}{W_{\text{false}}} \right) \times 100\% = \left( \frac{\text{Error}}{\text{False Weight}} \right) \times 100\%$$

### 2. Inverse Problem (Finding False Weight from Target Gain)

- If a dealer claims to sell at cost price and earns $g\%$ profit, the false weight used per kilogram ($1000\text{ g}$) is:
  $$W_{\text{false}} = \frac{1000 \times 100}{100 + g} = \frac{100000}{100 + g} \text{ grams}$$

### 3. Dual Cheating (Markup + False Weight / Cheating on Buying & Selling)

- If a trader marks up goods by $m\%$ AND uses false weight $W_{\text{false}}$ for true weight $W_{\text{true}}$:
  $$\text{Effective Gain Ratio} = \left(1 + \frac{m}{100}\right) \times \left( \frac{W_{\text{true}}}{W_{\text{false}}} \right) - 1$$
