# CDS Practice Q32: Linear HCF Parameter Evaluation Formula

## Question Text

If $(x + k)$ is the HCF of $P(x) = x^2 + ax + b$ and $Q(x) = x^2 + px + q$, then what is the value of $k$?

**Options:**
- (a) $\frac{b+q}{a+p}$
- (b) $\frac{b-q}{a-p}$
- (c) $\frac{a+b}{p+q}$
- (d) $\frac{a-b}{p-q}$

---

## Detailed Mathematical Solution

### Step 1: Apply Factor Theorem
Since $(x + k)$ is the HCF of both quadratic polynomials, $x = -k$ must be a zero for both $P(x)$ and $Q(x)$:

1. $P(-k) = 0 \implies (-k)^2 + a(-k) + b = 0 \implies k^2 - ak + b = 0$
2. $Q(-k) = 0 \implies (-k)^2 + p(-k) + q = 0 \implies k^2 - pk + q = 0$

### Step 2: Equate the Two Polynomial Equations
Subtract the second equation from the first:
$$(k^2 - ak + b) - (k^2 - pk + q) = 0$$
$$-ak + pk + b - q = 0$$
$$(p - a)k = q - b$$
$$(a - p)k = b - q$$
$$k = \frac{b - q}{a - p}$$

**Correct Answer**: **(b) $\frac{b - q}{a - p}$**

---

## Key Takeaway & Exam Strategy
This is a standard algebraic result. Memorize the formula $k = \frac{b-q}{a-p}$ for two quadratics $x^2+ax+b$ and $x^2+px+q$ sharing linear HCF $(x+k)$.
