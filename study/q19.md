# CDS Practice Q19

## Question
The expression $\sin(n+1)A \sin(n-1)A + \cos(n+1)A \cos(n-1)A$ is equal to:

- (a) $\sin 2A$
- (b) $\cos 2A$
- (c) $\tan 2A$
- (d) $\cot 2A$

---

## Detailed Step-by-Step Solution

### Step 1: Recognize Cosine Difference Formula Pattern
Recall the compound angle formula:
$$\cos(X - Y) = \cos X \cos Y + \sin X \sin Y$$

### Step 2: Substitute $X = (n+1)A$ and $Y = (n-1)A$
$$S = \cos(n+1)A \cos(n-1)A + \sin(n+1)A \sin(n-1)A$$
$$S = \cos \Big( (n+1)A - (n-1)A \Big)$$

### Step 3: Simplify Angle Difference
$$(n+1)A - (n-1)A = nA + A - nA + A = 2A$$
$$S = \cos(2A)$$

---

## Key Takeaway & Atomic Theorem Reference
- Expansion collapse: $\cos X \cos Y + \sin X \sin Y = \cos(X-Y)$.
- Reference Note: [Compound & Multiple Angles](/cds/math/notes/subtopics/compound_angles)

**Correct Answer**: **(b) $\cos 2A$**
