## 1. Data Type
A **Data Type** defines the *kind* of data a variable can hold and the operations allowed on it.
- **Primitive**: `int`, `float`, `char`
- **Derived**: `array`, `pointer`, `struct`, `union`
- **Abstract**: `Stack`, `Queue`, `Tree` (behavioral definitions)

## 2. Abstract Data Type (ADT)
An **ADT** is a *mathematical model* describing **what** operations can be performed, without specifying **how** they are implemented.
- It defines the *interface* (behavior) only.
- Examples: `List`, Stack` (LIFO), `Queue` (FIFO), `Map`, `Set`.

## 3. Data Structure
A **Data Structure** is the concrete **implementation** of an ADT in memory.
- It defines **how** data is organized, stored, and accessed.
- Examples: `Array` (for Stack), `Linked List` (for Queue), `HashMap` (for Map).
