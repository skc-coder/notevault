# Question 64: Bounded Range Optimization in 3-Set Venn Diagram

## Question
In a gathering of 100 people, 70 of them can speak Hindi, 60 can speak English and 30 can speak French. Further, 30 of them can speak both Hindi and English, 20 can speak both Hindi and French. If $x$ is the number of people who can speak both English and French, then which one of the following is correct? (Assume that everyone can speak at least one of the three languages) [CDS 2016 I]
- (a) $10 < x \le 30$
- (b) $0 \le x < 8$
- (c) $x = 9$
- (d) $x = 8$

---

## Detailed Solution using Disjoint 8-Region Method

```
                  +-----------------------------------+
                  |        Universal Set (Total = 100)|
                  |   +-----------+   +-----------+   |
                  |  /   Hindi     \ /   English   \  |
                  | /               X               \ |
                  | |   a (Only H) | |  b (Only E)  | |
                  | |       \   d  / \   e   /      | |
                  | |        (H∩E)     (E∩F)        | |
                  | |         +-----+-----+         | |
                  | \        /   |   |   \        / |
                  |  \      /  f | g |    \      /  |
                  |   +----+ (H∩F)|   +----+   |
                  |         \    |   |    /         |
                  |          +---+---+---+          |
                  |             / c (Only F)\       |
                  |            +-------------+      |
                  |  h = 0 (Everyone speaks ≥1)     |
                  +-----------------------------------+
```

### Step 1: Variable Definition & Equations
Let regional variables be:
- $a, b, c$: Only Hindi, Only English, Only French
- $d = \text{Only } H \cap E$, $e = \text{Only } E \cap F$, $f = \text{Only } H \cap F$
- $g = H \cap E \cap F$ (All three languages)
- $h = 0$ (since everyone speaks $\ge 1$ language)

From given data:
1. $N(H \cup E \cup F) = 100$
2. $N(H) = a + d + f + g = 70$
3. $N(E) = b + d + e + g = 60$
4. $N(F) = c + e + f + g = 30$
5. $N(H \cap E) = d + g = 30 \implies d = 30 - g$
6. $N(H \cap F) = f + g = 20 \implies f = 20 - g$
7. $N(E \cap F) = e + g = x \implies e = x - g$

### Step 2: Apply Inclusion-Exclusion Master Equation
$$N(H \cup E \cup F) = N(H) + N(E) + N(F) - [N(H \cap E) + N(H \cap F) + N(E \cap F)] + g$$
$$100 = 70 + 60 + 30 - [30 + 20 + x] + g$$
$$100 = 160 - 50 - x + g$$
$$100 = 110 - x + g \implies x - g = 10 \implies g = x - 10$$

### Step 3: Apply Non-Negativity Bounds
1. **Lower Bound**: $g \ge 0 \implies x - 10 \ge 0 \implies x \ge 10$ (or $10 < x$ for $g > 0$).
2. **Upper Bound**: $x = N(E \cap F) \le N(F) = 30 \implies x \le 30$.

Combining bounds gives:
$$10 < x \le 30$$

Hence, option **(a)** is correct.

---

## Key Takeaway & Pattern
- Always express the central triple intersection $g$ in terms of the unknown $x$.
- Use region non-negativity $g \ge 0$ for the lower bound and set capacity limits for the upper bound!
