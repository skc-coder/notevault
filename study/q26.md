# CDS Practice Q26

## Question
If $p = \tan^2 x + \cot^2 x$, then which one of the following is correct?

- (a) $p \le 2$
- (b) $p \ge 2$
- (c) $p < 2$
- (d) $p > 2$

---

## Detailed Step-by-Step Solution

### Step 1: Apply AM-GM Inequality
For positive real numbers $a = \tan^2 x$ and $b = \cot^2 x$:
$$\frac{a + b}{2} \ge \sqrt{ab}$$
$$\frac{\tan^2 x + \cot^2 x}{2} \ge \sqrt{\tan^2 x \cdot \cot^2 x} = \sqrt{1} = 1$$
$$p = \tan^2 x + \cot^2 x \ge 2$$

### Step 2: Perfect Square Method (Alternative Proof)
$$p = (\tan x - \cot x)^2 + 2 \cdot \tan x \cdot \cot x = (\tan x - \cot x)^2 + 2$$
Since $(\tan x - \cot x)^2 \ge 0$ for all real values of $x$:
$$p \ge 0 + 2 \implies p \ge 2$$

Equality holds when $\tan x = \cot x \implies x = 45^\circ$.

---

## Key Takeaway & Atomic Theorem Reference
- AM-GM Inequality: $A + B \ge 2\sqrt{AB}$ for non-negative real terms.
- Reference Note: [Extrema & Triangle Properties](/cds/math/notes/subtopics/trig_extrema)

**Correct Answer**: **(b) $p \ge 2$**
